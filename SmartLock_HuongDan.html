1. Giới thiệu đề tài

Hệ thống dùng vi điều khiển ESP32 làm Web Server. ESP32 tự phát WiFi riêng. Người dùng kết nối điện thoại vào WiFi này, mở trình duyệt và thấy giao diện bàn phím số (Keypad). Khi nhập đúng mã PIN, ESP32 điều khiển Servo (hoặc Relay nối khóa chốt điện) để mở khóa và bật LED xanh. Khi nhập sai, LED đỏ nhấp nháy để cảnh báo.

Mục tiêu

  • Xây dựng Web Server trên ESP32, có giao diện keypad thân thiện với điện thoại.
  • Điều khiển cơ cấu chấp hành (Servo/Relay) và đèn báo trạng thái (LED xanh/đỏ).
  • Áp dụng bảo mật: kiểm tra dữ liệu đầu vào, so sánh chuỗi an toàn, chống dò mật khẩu, tự động khóa lại.
  • Cho phép đổi PIN và lưu PIN vào bộ nhớ flash, mất điện không mất.

  2. Điện thoại truy cập http://192.168.4.1, nhận về trang HTML có bàn phím số.
  3. Người dùng nhập PIN rồi bấm OK. Trình duyệt gửi yêu cầu POST /unlock kèm PIN.
  4. ESP32 kiểm tra định dạng PIN, sau đó so sánh với PIN đã lưu:

    • Sai: LED đỏ nháy 3 lần và tăng bộ đếm. Sai 3 lần thì khóa tạm 30 giây.
  5. Trang web hỏi GET /status mỗi giây để cập nhật trạng thái hiển thị.

⚠️ Những lỗi cần tránh
  • Tuyệt đối không để dây 12V chạm vào bất kỳ chân nào của ESP32, nếu không board sẽ cháy.
  • Tất cả GND (ESP32, servo, LED, relay) phải nối chung với nhau.
  • Không dùng các chân GPIO 6–11 (bị nối với bộ nhớ flash) và GPIO 34–39 (chỉ đọc được, không xuất tín hiệu).
  • Hạn chế dùng các chân GPIO 0, 2, 12, 15 vì chúng ảnh hưởng đến quá trình khởi động.
  • Nếu servo quay mà ESP32 bị reset, nghĩa là cổng USB không cấp đủ dòng. Khi đó cấp cho servo một nguồn 5V riêng, nhưng vẫn phải nối GND chung với ESP32.
  • Luôn rút cáp USB trước khi cắm hoặc tháo dây.

5. Cài đặt phần mềm

  1. Cài Arduino IDE 2.x từ trang arduino.cc/en/software.
  2. Thêm board ESP32:
    • Vào File → Preferences. Ở ô Additional boards manager URLs, dán đường dẫn:
      https://espressif.github.io/arduino-esp32/package_esp32_index.json
    • Vào Tools → Board → Boards Manager, tìm esp32 (của Espressif Systems) rồi bấm Install.
  3. Cài thư viện Servo: vào Sketch → Include Library → Manage Libraries, tìm ESP32Servo (tác giả Kevin Harrington) rồi bấm Install.
    Các thư viện WiFi.h, WebServer.h và Preferences.h có sẵn trong gói board ESP32, không cần cài thêm.
  4. Driver USB:
    • Windows: cài driver CP210x hoặc CH340, tùy loại chip USB in trên board.
    • Linux: chạy lệnh sudo usermod -aG dialout $USER rồi đăng xuất và đăng nhập lại.
    • macOS: thường nhận board ngay. Nếu board dùng chip CH340 thì cài thêm driver.

6. Nạp code vào ESP32

  1. Tạo thư mục SmartLock và lưu mã nguồn ở Phụ lục thành file SmartLock/SmartLock.ino. Tên file phải trùng với tên thư mục.
  2. Vào Tools → Board và chọn ESP32 Dev Module.
  3. Vào Tools → Port và chọn cổng của board (Windows: COMx, Linux: /dev/ttyUSB0, macOS: /dev/cu.usbserial-…).
  4. Bấm Upload (nút mũi tên →). Nếu hiện lỗi Failed to connect… Connecting…, hãy giữ nút BOOT trên board cho đến khi thấy chữ Writing….
  5. Mở Serial Monitor, chọn tốc độ 115200 baud rồi bấm nút EN (reset). Màn hình sẽ hiện: 
    WiFi: SmartLock-ESP32
Mo trinh duyet: http://192.168.4.1
Mẹo: nên làm từng phần một. Cắm 2 LED trước, nạp code và thử trên web cho chạy được, rồi mới cắm thêm servo và relay. Như vậy nếu có lỗi sẽ dễ tìm ra chỗ sai.

7. Hướng dẫn sử dụng

  1. Trên điện thoại, kết nối WiFi SmartLock-ESP32 với mật khẩu 12345678. Nếu điện thoại báo "không có Internet" thì chọn Vẫn kết nối.
  2. Mở trình duyệt và vào http://192.168.4.1.
  3. Nhập PIN mặc định 1234 rồi bấm OK. Servo mở, LED xanh sáng. Sau 5 giây khóa tự đóng lại.
  4. Bấm nút Khóa ngay nếu muốn khóa trước khi hết 5 giây.
  5. Mở mục Đổi mã PIN, nhập PIN cũ và PIN mới (4–8 chữ số) rồi bấm Lưu. PIN mới được ghi vào flash.

8.3 Đoạn code chính: xử lý mở khóa

void handleUnlock() {
  unsigned long remain = lockoutRemainingSec();
  if (remain > 0) { ... từ chối vì đang tạm khóa ... }

  String pin = server.arg("pin");   // lấy PIN từ body POST
  pin.trim();                       // bỏ khoảng trắng thừa
  if (!isValidPin(pin)) { ... }     // chỉ chấp nhận 4-8 chữ số

  if (safeEquals(pin, currentPin)) {
    failCount = 0;
    unlockDoor();                   // servo 90°, relay ON, LED xanh
  } else {
    failCount++;
    wrongPinAlert();                // LED đỏ nháy, còi kêu
    if (failCount >= MAX_FAILS) {   // sai 3 lần -> tạm khóa 30s
      lockedOut = true;
      lockoutStart = millis();
    }
  }
}

8.4 Tự động khóa lại (không dùng delay)

void loop() {
  server.handleClient();
  if (!isLocked && millis() - unlockedAt >= AUTO_LOCK_MS) {
    lockDoor();
  }
}

Chương trình dùng millis() thay cho delay() để ESP32 vẫn tiếp tục phục vụ trang web trong lúc chờ khóa lại. Cách viết phép trừ millis() - unlockedAt vẫn đúng ngay cả khi millis() bị tràn số (sau khoảng 49 ngày).

8.5 Giao diện web (JavaScript)

  • Các phím 0–9 ghép số vào biến pin. Màn hình chỉ hiện dấu ●, không hiện số thật.
  • Khi bấm OK, trang gửi fetch('/unlock', {method:'POST', body: URLSearchParams}), sau đó hiển thị thông báo từ JSON trả về và xóa PIN vừa nhập.
  • Hàm setInterval(refresh, 1000) cập nhật trạng thái mỗi giây, gồm cả số giây tạm khóa còn lại.

Ước tính độ an toàn: PIN 4 chữ số có 10.000 tổ hợp. Mỗi 3 lần thử bị chặn 30 giây, nên để thử hết toàn bộ tổ hợp cần khoảng 10.000 / 3 × 30s ≈ 27,8 giờ. Với PIN 6 chữ số, con số này tăng lên khoảng 115 ngày.

Hạn chế (nên nêu trong báo cáo): dữ liệu truyền qua HTTP không được mã hóa, nên ai bắt gói tin trong cùng mạng WiFi có thể đọc được PIN. PIN cũng đang được lưu dưới dạng chuỗi gốc. Xem cách khắc phục ở mục Hướng phát triển.

12. Hướng phát triển

  • Chế độ STA: cho ESP32 kết nối vào WiFi nhà bằng WiFi.begin(ssid, pass) để truy cập từ mọi thiết bị trong mạng.
  • Băm PIN: chỉ lưu SHA-256(salt + PIN) bằng thư viện mbedtls có sẵn trên ESP32, không lưu chuỗi gốc.
  • HTTPS / mã hóa: dùng chứng chỉ tự ký hoặc đưa hệ thống lên MQTT qua TLS.
  • Nhật ký truy cập: ghi lại thời gian mở cửa và số lần nhập sai (đồng bộ giờ qua NTP), hiển thị trên trang quản trị.
  • Thông báo: gửi tin nhắn Telegram hoặc email khi có người nhập sai nhiều lần.
  • Mã OTP dùng một lần để cấp quyền vào cửa tạm thời cho khách.
  • Xác thực đa lớp: thêm bàn phím 4x4 vật lý, thẻ RFID RC522 hoặc cảm biến vân tay.
  • Cảm biến cửa: dùng công tắc từ (reed switch) để biết cửa đang thực sự mở hay đóng.

 * KHÓA CỬA THÔNG MINH - NHẬP PIN TRÊN WEB (ESP32)

// ================= XỬ LÝ CHUỖI / BẢO MẬT =================
bool isValidPin(const String& p) {
  if (p.length() < 4 || p.length() > 8) return false;
  for (size_t i = 0; i < p.length(); i++) {
    if (!isDigit(p[i])) return false;
  }
  return true;
}

// So sánh thời gian cố định: không thoát sớm khi gặp ký tự sai
bool safeEquals(const String& a, const String& b) {
  if (a.length() != b.length()) return false;
  uint8_t diff = 0;
  for (size_t i = 0; i < a.length(); i++) diff |= a[i] ^ b[i];
  return diff == 0;
}

unsigned long lockoutRemainingSec() {
  if (!lockedOut) return 0;
  unsigned long elapsed = millis() - lockoutStart;
  if (elapsed >= LOCKOUT_MS) {
    lockedOut = false;
    return 0;
  }
  return (LOCKOUT_MS - elapsed) / 1000 + 1;
}

// ================= ĐIỀU KHIỂN PHẦN CỨNG =================
void setRelay(bool on) {
  digitalWrite(RELAY_PIN, (on ^ RELAY_ACTIVE_LOW) ? HIGH : LOW);
}

void beep(int times, int ms) {
  for (int i = 0; i < times; i++) {
    digitalWrite(BUZZER_PIN, HIGH);
    delay(ms);
    digitalWrite(BUZZER_PIN, LOW);
    delay(ms);
  }
}

void lockDoor() {
  isLocked = true;
  lockServo.write(SERVO_LOCKED);
  setRelay(false);
  digitalWrite(LED_GREEN, LOW);
  digitalWrite(LED_RED, HIGH);
  Serial.println("[LOCK] Da khoa");
}

void unlockDoor() {
  isLocked = false;
  unlockedAt = millis();
  lockServo.write(SERVO_UNLOCKED);
  setRelay(true);
  digitalWrite(LED_GREEN, HIGH);
  digitalWrite(LED_RED, LOW);
  beep(1, 150);
  Serial.println("[LOCK] Da mo");
}

void wrongPinAlert() {
  for (int i = 0; i < 3; i++) {
    digitalWrite(LED_RED, LOW);
    digitalWrite(BUZZER_PIN, HIGH);
    delay(100);
    digitalWrite(LED_RED, HIGH);
    digitalWrite(BUZZER_PIN, LOW);
    delay(100);
  }
}

// ================= HTTP HANDLERS =================
void sendJson(bool ok, const String& msg) {
  server.send(200, "application/json", "{\"ok\":" + String(ok ? "true" : "false") + ",\"msg\":\"" + msg + "\"}");
}

void handleRoot() {
  server.send_P(200, "text/html", PAGE_HTML);
}

void handleStatus() {
  String json = "{\"locked\":" + String(isLocked ? "true" : "false") +
                ",\"lockout\":" + String(lockoutRemainingSec()) + "}";
  server.send(200, "application/json", json);
}

void handleUnlock() {
  unsigned long remain = lockoutRemainingSec();
  if (remain > 0) {
    sendJson(false, "Sai quá nhiều lần! Thử lại sau " + String(remain) + "s");
    return;
  }

  String pin = server.arg("pin");
  pin.trim();
  if (!isValidPin(pin)) {
    sendJson(false, "PIN không hợp lệ (chỉ 4-8 chữ số)");
    return;
  }

  if (safeEquals(pin, currentPin)) {
    failCount = 0;
    unlockDoor();
    sendJson(true, "Mở khóa thành công!");
  } else {
    failCount++;
    Serial.printf("[WARN] Sai PIN lan %d\n", failCount);
    wrongPinAlert();
    if (failCount >= MAX_FAILS) {
      failCount = 0;
      lockedOut = true;
      lockoutStart = millis();
      sendJson(false, "Sai " + String(MAX_FAILS) + " lần! Tạm khóa " + String(LOCKOUT_MS / 1000) + "s");
    } else {
      sendJson(false, "Sai PIN! Còn " + String(MAX_FAILS - failCount) + " lần thử");
    }
  }
}

void handleLock() {
  lockDoor();
  sendJson(true, "Đã khóa cửa");
}

void handleChangePin() {
  String oldPin = server.arg("old");
  String newPin = server.arg("new");
  oldPin.trim();
  newPin.trim();

  if (lockoutRemainingSec() > 0) {
    sendJson(false, "Đang bị tạm khóa");
    return;
  }
  if (!safeEquals(oldPin, currentPin)) {
    sendJson(false, "PIN cũ không đúng");
    return;
  }
  if (!isValidPin(newPin)) {
    sendJson(false, "PIN mới phải gồm 4-8 chữ số");
    return;
  }

  currentPin = newPin;
  prefs.putString("pin", currentPin);
  Serial.println("[INFO] Da doi PIN");
  sendJson(true, "Đổi PIN thành công!");
}

// ================= SETUP / LOOP =================
void setup() {
  Serial.begin(115200);

  pinMode(RELAY_PIN, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);
  pinMode(LED_RED, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);

  lockServo.setPeriodHertz(50);
  lockServo.attach(SERVO_PIN, 500, 2400);

  prefs.begin("smartlock", false);
  currentPin = prefs.getString("pin", DEFAULT_PIN);

  lockDoor();

  WiFi.softAP(AP_SSID, AP_PASS);
  Serial.print("WiFi: ");
  Serial.println(AP_SSID);
  Serial.print("Mo trinh duyet: http://");
  Serial.println(WiFi.softAPIP());

  server.on("/", HTTP_GET, handleRoot);
  server.on("/status", HTTP_GET, handleStatus);
  server.on("/unlock", HTTP_POST, handleUnlock);
  server.on("/lock", HTTP_POST, handleLock);
  server.on("/changepin", HTTP_POST, handleChangePin);
  server.begin();
}

void loop() {
  server.handleClient();

  if (!isLocked && millis() - unlockedAt >= AUTO_LOCK_MS) {
    lockDoor();
  }
}
