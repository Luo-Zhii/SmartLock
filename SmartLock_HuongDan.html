1. Giới thiệu đề tài

Hệ thống dùng vi điều khiển ESP32 làm Web Server. ESP32 tự phát WiFi riêng. Người dùng kết nối điện thoại vào WiFi này và mở trình duyệt để thấy giao diện bàn phím số. Khi nhập đúng mã PIN, ESP32 kích Relay (đóng vai trò chốt khóa điện) để mở khóa và bật LED xanh. Khi nhập sai, LED đỏ nháy và còi kêu. Nếu nhập sai nhiều lần hoặc cửa bị mở khi đang khóa, hệ thống báo động.

Ngoài phần bắt buộc của đề bài, hệ thống tận dụng thêm các linh kiện có sẵn trong bộ kit: màn hình OLED hiển thị trạng thái, cảm biến PIR phát hiện người đến gần cửa, cảm biến hồng ngoại làm cảm biến cửa đóng/mở, và 2 nút nhấn đặt phía trong nhà.

Mục tiêu

  • Xây dựng Web Server trên ESP32 với giao diện keypad dùng trên điện thoại, hiển thị trạng thái theo thời gian thực.
  • Điều khiển cơ cấu chấp hành (Relay) và các thiết bị báo hiệu (LED xanh/vàng/đỏ, OLED, còi).
  • Áp dụng bảo mật: kiểm tra dữ liệu đầu vào, so sánh chuỗi an toàn, chống dò mật khẩu, báo động đột nhập, ghi nhật ký.
  • Cho phép đổi PIN và lưu PIN vào bộ nhớ flash, mất điện không mất.

4.3 Bố trí đường nguồn trên breadboard

Breadboard 830 lỗ có 2 cặp đường nguồn chạy dọc hai mép (vạch đỏ + và vạch xanh −). Mình dùng 2 cặp này như sau:

Mép trên :  (+) = 3V3   ← dây từ chân 3V3 của ESP32     → cấp cho OLED, cảm biến IR
            (−) = GND   ← dây từ chân GND của ESP32
Mép dưới :  (+) = 5V    ← dây từ chân VIN của ESP32     → cấp cho Relay, PIR, còi báo động
            (−) = GND   ← nối 1 dây sang (−) mép trên
⚠️ Không được để đường 3V3 và đường 5V chạm nhau. Một số breadboard còn bị đứt đường nguồn ở giữa (vạch màu bị ngắt quãng). Nếu breadboard của bạn như vậy, hãy cắm thêm dây nối hai nửa lại.

4.4 Số lượng dây cần dùng

Breadboard 830 lỗ hơi hẹp so với ESP32. Cắm ESP32 lên thì một bên chỉ còn 1 hàng lỗ trống, rất khó cắm dây. Vì vậy nên đặt ESP32 bên ngoài breadboard và cắm đầu cái của dây Dupont thẳng vào chân ESP32:

Loại dâyDùng cho
F-F (cái-cái)Nối thẳng từ chân ESP32 sang chân module: SDA, SCL, IN1, IN2, OUT của IR, OUT của PIR
F-M (cái-đực)Nối từ chân ESP32 xuống breadboard (3V3, VIN, GND, 3 LED, còi, 2 nút) và từ breadboard lên chân nguồn của các module
M-M (đực-đực)Nối giữa 2 điểm trên breadboard (GND mép trên ↔ mép dưới, chân GND của nút) và nối vào cọc vít của relay
Thiếu dây F-M? Cắm nối một dây F-F với một dây M-M là được một dây F-M. Nếu vẫn thiếu, dây Dupont bán theo bó 40 sợi rất rẻ. Ngoài ra ESP32 có 2–3 chân GND, nên một số module có thể lấy GND trực tiếp từ ESP32 bằng dây F-F.
⚠️ Những lỗi cần tránh
  • Luôn rút cáp USB trước khi cắm hoặc tháo dây.
  • Không cấp 5V cho OLED hay cảm biến IR khi chân tín hiệu của chúng nối thẳng vào ESP32. Hai module này dùng 3V3.
  • Tất cả GND phải nối chung với nhau.
  • GPIO 34 và 35 chỉ đọc được (input-only), nên chỉ dùng cho cảm biến. Không dùng GPIO 6–11 vì chúng nối với bộ nhớ flash.
  • Cắm LED đúng chiều: chân dài nối phía GPIO, chân ngắn nối GND.

5. Lắp ráp từng bước (thử đến đâu chắc đến đó)

Không nên cắm hết một lần. Hãy lắp từng phần, nạp code và kiểm tra rồi mới lắp tiếp. Code đã được viết để thiếu linh kiện nào thì chỉ phần đó không chạy, các phần khác vẫn hoạt động bình thường.

Bước 1: Nguồn + 3 LED

Đi dây 3V3/5V/GND ra breadboard. Cắm 3 LED kèm điện trở. Nạp code: LED đỏ sáng. Vào web nhập 1234 thì LED xanh sáng.

Bước 2: OLED

Nối 4 dây. Bấm nút EN để khởi động lại: màn hình hiện LOCKED và IP 192.168.4.1.

Bước 3: Còi thụ động + 2 nút

Bấm EXIT: nghe giai điệu, LED xanh sáng. Bấm LOCK: kêu "tít", khóa lại.

Bước 4: Relay 2 kênh

Nối VCC, GND, IN1, IN2. Mở khóa thì relay 1 kêu "tách" và đèn trên relay sáng.

Bước 5: Còi báo động qua relay CH2

COM2 nối 5V, NO2 nối còi (+), còi (−) nối GND. Nhập sai 3 lần thì còi kêu 15 giây.

Bước 6: Cảm biến IR (cửa)

Chỉnh biến trở trên module sao cho đưa tay cách khoảng 3–5cm thì đèn trên module sáng. Tay che = cửa đóng, bỏ tay ra = cửa mở.

Bước 7: PIR

Chờ khoảng 30–60 giây sau khi cấp điện để PIR ổn định. Vẫy tay trước PIR: LED vàng sáng, OLED bật lên.

Bước 8: Làm mô hình

Gắn các linh kiện lên hộp carton hoặc mô hình cửa. Đặt cảm biến IR hướng vào cánh cửa, PIR hướng ra phía ngoài cửa.

Chỉnh PIR HC-SR501: trên module có 2 biến trở.
  • Sx (sensitivity): chỉnh khoảng cách phát hiện, từ 3 đến 7m.
  • Tx (time delay): chỉnh thời gian giữ tín hiệu. Nên vặn hết ngược chiều kim đồng hồ (khoảng 3 giây) để phản hồi nhanh.
Jumper chọn chế độ nên đặt ở H (repeat trigger), nghĩa là còn thấy người thì còn giữ tín hiệu.
Chưa lắp cảm biến cửa (IR)? Hãy đặt USE_DOOR_SENSOR = false trong code. Nếu không, chân GPIO 34 để trống sẽ đọc giá trị lung tung và gây báo động giả.

6. Cài đặt phần mềm

  1. Cài Arduino IDE 2.x từ trang arduino.cc/en/software.
  2. Thêm board ESP32:
    • Vào File → Preferences. Ở ô Additional boards manager URLs, dán đường dẫn:
      https://espressif.github.io/arduino-esp32/package_esp32_index.json
    • Vào Tools → Board → Boards Manager, tìm esp32 (của Espressif Systems) rồi bấm Install. Đừng nhầm với gói "Arduino ESP32 Boards".
  3. Cài thư viện: vào Sketch → Include Library → Manage Libraries và cài 2 thư viện:
    • Adafruit SSD1306: khi được hỏi có cài các thư viện phụ thuộc không, chọn Install All.
    • Adafruit GFX Library: thường đã được cài cùng ở bước trên.
    Các thư viện WiFi, WebServer, Preferences và Wire có sẵn trong gói board ESP32.
  4. Driver USB:
    • Windows: cài driver CP210x hoặc CH340, tùy loại chip USB in trên board.
    • Linux: chạy lệnh sudo usermod -aG dialout $USER rồi đăng xuất và đăng nhập lại.

7. Nạp code vào ESP32

  1. Tạo thư mục SmartLock và lưu mã nguồn ở Phụ lục thành file SmartLock/SmartLock.ino. Tên file phải trùng với tên thư mục.
  2. Vào Tools → Board và chọn ESP32 Dev Module. Vào Tools → Port và chọn cổng COM (Windows) hoặc /dev/ttyUSB0 (Linux).
  3. Bấm Upload. Nếu hiện lỗi Failed to connect… Connecting…, hãy giữ nút BOOT trên board cho đến khi thấy chữ Writing….
  4. Mở Serial Monitor, chọn tốc độ 115200 baud rồi bấm nút EN. Màn hình sẽ hiện: 
    00:00:00 Khóa cửa (khởi động)
WiFi: SmartLock-ESP32
Mo trinh duyet: http://192.168.4.1

Code đã được biên dịch thử trên core ESP32 3.3.12 (của Espressif) với thư viện Adafruit SSD1306 2.5.17 và Adafruit GFX 1.12.6. Chương trình chiếm khoảng 75% bộ nhớ flash.

8. Hướng dẫn sử dụng

  1. Trên điện thoại, kết nối WiFi SmartLock-ESP32 với mật khẩu 12345678. Nếu điện thoại báo "không có Internet" thì chọn Vẫn kết nối, và tắt dữ liệu di động (4G).
  2. Mở trình duyệt và vào http://192.168.4.1. Địa chỉ này cũng hiện ở dòng cuối của OLED.
  3. Phần đầu trang có 4 ô trạng thái: Khóa, Cửa, Có người, Báo động.
  4. Nhập PIN mặc định 1234 rồi bấm OK để mở khóa.
  5. Mục Đổi mã PIN: nhập PIN cũ và PIN mới (4–8 chữ số).
  6. Mục Nhật ký: xem 8 sự kiện gần nhất kèm thời gian tính từ lúc khởi động.

Cách tắt báo động

  • Nhập đúng PIN trên web (chỉ được khi không đang trong 30 giây tạm khóa).

9.3 Xử lý mở khóa

void handleUnlock() {
  if (lockoutRemainingSec() > 0) { ... từ chối vì đang tạm khóa ... }

  String pin = server.arg("pin");      // lấy PIN từ body của POST
  pin.trim();                          // bỏ khoảng trắng thừa
  if (!isValidPin(pin)) { ... }        // chỉ nhận 4-8 chữ số

  if (safeEquals(pin, currentPin)) {   // so sánh thời gian cố định
    unlockDoor("PIN trên web");        // relay 1 ON, LED xanh, tắt báo động
    playSuccess();
    return;
  }
  failCount++;
  if (failCount >= MAX_FAILS) {        // sai 3 lần
    lockedOut = true;                  // tạm khóa 30s
    startAlarm("sai PIN 3 lần");       // relay 2 ON -> còi báo động
  }
  playFail();
}

9.4 Cảm biến cửa và phát hiện đột nhập

bool open = digitalRead(PIN_DOOR_IR) == HIGH;  // không thấy cánh cửa -> cửa mở
if (open != doorOpen) {                        // chỉ xử lý khi trạng thái THAY ĐỔI
  doorOpen = open;
  if (open && isLocked) startAlarm("cửa bị mở khi đang khóa");
}

Chương trình chỉ phản ứng khi trạng thái thay đổi (gọi là bắt cạnh, edge detection), nên mỗi lần cửa mở chỉ báo động một lần. Lúc khởi động, trạng thái cửa được đọc trước để tránh báo động giả.

9.5 Tự khóa lại an toàn

if (!isLocked && millis() - unlockedAt >= AUTO_LOCK_MS && !(USE_DOOR_SENSOR && doorOpen)) {
  lockDoor("tự động");
}

Hệ thống chỉ khóa lại khi đã hết 5 giây và cửa đã đóng. Nếu cửa vẫn đang mở, nó sẽ chờ, vì khóa khi cửa mở thì chốt không vào được. Chương trình dùng millis() thay cho delay() để ESP32 vẫn phục vụ web, đọc nút và cảm biến trong lúc chờ. Phép trừ millis() - mốc vẫn đúng kể cả khi millis() bị tràn số (sau khoảng 49 ngày).

9.6 Nút nhấn có chống dội (debounce)

bool pressed(Button& b) {
  bool now = digitalRead(b.pin);                       // INPUT_PULLUP: thả = HIGH, nhấn = LOW
  if (now != b.last && millis() - b.changedAt > 50) {  // bỏ qua nhiễu dưới 50ms
    b.changedAt = millis();
    b.last = now;
    return now == LOW;                                 // chỉ trả true lúc vừa nhấn xuống
  }
  return false;
}

9.7 Giao diện web

  • Các phím 0–9 ghép số vào biến pin. Màn hình chỉ hiện dấu ●, không hiện số thật.
  • Khi bấm OK, trang gửi fetch('/unlock', {method:'POST', body: URLSearchParams}) và hiển thị thông báo từ JSON trả về.
  • setInterval(refresh, 1000) gọi /status mỗi giây để cập nhật 4 ô trạng thái và nhật ký.

13. Hướng phát triển

  • Tận dụng linh kiện còn lại: hiển thị nhiệt độ/độ ẩm (DHT11) lên OLED; dùng quang trở để giảm độ sáng màn hình vào ban đêm; dùng chiết áp để chỉnh thời gian tự khóa.
  • Chế độ STA: cho ESP32 kết nối vào WiFi nhà bằng WiFi.begin(ssid, pass) để truy cập từ mọi thiết bị trong mạng.
  • Băm PIN: chỉ lưu SHA-256(salt + PIN) bằng thư viện mbedtls có sẵn trên ESP32, không lưu chuỗi gốc.
  • Mã hóa đường truyền: HTTPS với chứng chỉ tự ký, hoặc MQTT qua TLS.
  • Thông báo từ xa: gửi tin nhắn Telegram khi có báo động.
  • Mã OTP dùng một lần để cấp quyền vào cửa tạm thời cho khách.
  • Khóa thật: nối relay kênh 1 với khóa chốt điện 12V (dùng adapter 12V riêng, mắc thêm diode 1N4007 song song với cuộn hút của khóa).
  • Thêm cách mở thứ hai: thẻ RFID RC522 hoặc cảm biến vân tay.

// ================= TIỆN ÍCH =================
String uptimeStr() {
  unsigned long s = millis() / 1000;
  char buf[12];
  snprintf(buf, sizeof(buf), "%02lu:%02lu:%02lu", s / 3600, (s / 60) % 60, s % 60);
  return buf;
}

void addLog(const String& msg) {
  for (int i = LOG_SIZE - 1; i > 0; i--) logs[i] = logs[i - 1];
  logs[0] = uptimeStr() + " " + msg;
  if (logCount < LOG_SIZE) logCount++;
  Serial.println(logs[0]);
}

void touch() {
  lastActivity = millis();
}

// Thông báo ngắn trên OLED (chỉ ASCII, không dấu)
void showMsg(const String& m) {
  oledMsg = m;
  oledMsgAt = millis();
  touch();
}

// ================= XỬ LÝ CHUỖI / BẢO MẬT =================
bool isValidPin(const String& p) {
  if (p.length() < 4 || p.length() > 8) return false;
  for (size_t i = 0; i < p.length(); i++) {
    if (!isDigit(p[i])) return false;
  }
  return true;
}

// So sánh thời gian cố định: không thoát sớm khi gặp ký tự sai
bool safeEquals(const String& a, const String& b) {
  if (a.length() != b.length()) return false;
  uint8_t diff = 0;
  for (size_t i = 0; i < a.length(); i++) diff |= a[i] ^ b[i];
  return diff == 0;
}

unsigned long lockoutRemainingSec() {
  if (!lockedOut) return 0;
  unsigned long elapsed = millis() - lockoutStart;
  if (elapsed >= LOCKOUT_MS) {
    lockedOut = false;
    return 0;
  }
  return (LOCKOUT_MS - elapsed) / 1000 + 1;
}

// ================= ĐIỀU KHIỂN PHẦN CỨNG =================
void setRelay(int pin, bool on) {
  digitalWrite(pin, (on ^ RELAY_ACTIVE_LOW) ? HIGH : LOW);
}

void playSuccess() {
  tone(PIN_BUZZER, 1047, 120); delay(140);
  tone(PIN_BUZZER, 1319, 120); delay(140);
  tone(PIN_BUZZER, 1568, 200); delay(220);
  noTone(PIN_BUZZER);
}

void playFail() {
  for (int i = 0; i < 2; i++) {
    digitalWrite(PIN_LED_RED, LOW);
    tone(PIN_BUZZER, 300, 180); delay(200);
    digitalWrite(PIN_LED_RED, HIGH);
    delay(120);
  }
  noTone(PIN_BUZZER);
}

void playClick() {
  tone(PIN_BUZZER, 880, 80); delay(100);
  noTone(PIN_BUZZER);
}

void startAlarm(const String& reason) {
  if (!alarmOn) addLog("BÁO ĐỘNG: " + reason);
  alarmOn = true;
  alarmStart = millis();
  setRelay(PIN_RELAY_ALARM, true);
  touch();
}

void stopAlarm() {
  if (!alarmOn) return;
  alarmOn = false;
  setRelay(PIN_RELAY_ALARM, false);
  addLog("Tắt báo động");
}

void lockDoor(const String& source) {
  isLocked = true;
  setRelay(PIN_RELAY_LOCK, false);
  digitalWrite(PIN_LED_GREEN, LOW);
  digitalWrite(PIN_LED_RED, HIGH);
  addLog("Khóa cửa (" + source + ")");
  showMsg("Da khoa cua");
}

void unlockDoor(const String& source) {
  isLocked = false;
  unlockedAt = millis();
  failCount = 0;
  stopAlarm();
  setRelay(PIN_RELAY_LOCK, true);
  digitalWrite(PIN_LED_GREEN, HIGH);
  digitalWrite(PIN_LED_RED, LOW);
  addLog("Mở khóa (" + source + ")");
  showMsg("Moi vao!");
}

// LED vàng: nháy nhanh khi báo động, nháy chậm khi tạm khóa, sáng khi có người
void updateYellowLed() {
  unsigned long t = millis();
  if (alarmOn) digitalWrite(PIN_LED_YELLOW, (t / 150) % 2);
  else if (lockoutRemainingSec() > 0) digitalWrite(PIN_LED_YELLOW, (t / 500) % 2);
  else digitalWrite(PIN_LED_YELLOW, motion ? HIGH : LOW);
}

// ================= CẢM BIẾN & NÚT NHẤN =================
bool readDoorOpen() {
  // Module tránh vật cản: OUT = LOW khi thấy vật cản (cánh cửa) -> cửa đóng
  return digitalRead(PIN_DOOR_IR) == HIGH;
}

void readSensors() {
  bool m = digitalRead(PIN_PIR) == HIGH;
  if (m && !motion) addLog("Phát hiện người trước cửa");
  motion = m;
  if (motion) touch();

  if (!USE_DOOR_SENSOR) return;
  bool open = readDoorOpen();
  if (open == doorOpen) return;
  doorOpen = open;
  addLog(open ? "Cửa mở" : "Cửa đóng");
  touch();
  if (open && isLocked) startAlarm("cửa bị mở khi đang khóa");
}

bool pressed(Button& b) {
  bool now = digitalRead(b.pin);
  if (now != b.last && millis() - b.changedAt > 50) {
    b.changedAt = millis();
    b.last = now;
    return now == LOW;
  }
  return false;
}

void handleButtons() {
  if (pressed(btnExit)) {
    unlockDoor("nút EXIT");
    playSuccess();
  }
  if (pressed(btnLock)) {
    stopAlarm();
    lockDoor("nút LOCK");
    playClick();
  }
}

// ================= OLED =================
void drawOled() {
  if (!oledOk) return;

  bool idle = isLocked && !alarmOn && lockoutRemainingSec() == 0;
  if (idle && millis() - lastActivity > SCREEN_TIMEOUT_MS) {
    if (screenOn) {
      display.ssd1306_command(SSD1306_DISPLAYOFF);
      screenOn = false;
    }
    return;
  }
  if (!screenOn) {
    display.ssd1306_command(SSD1306_DISPLAYON);
    screenOn = true;
  }

  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);

  display.setTextSize(1);
  display.setCursor(0, 0);
  display.print("SMART LOCK");
  if (USE_DOOR_SENSOR) {
    display.setCursor(80, 0);
    display.print(doorOpen ? "Cua:MO" : "Cua:DONG");
  }
  display.drawLine(0, 10, 127, 10, SSD1306_WHITE);

  display.setTextSize(2);
  display.setCursor(0, 16);
  unsigned long remain = lockoutRemainingSec();
  if (alarmOn) {
    display.print("! ALARM !");
  } else if (remain > 0) {
    display.print("WAIT ");
    display.print(remain);
    display.print("s");
  } else {
    display.print(isLocked ? "LOCKED" : "OPEN");
  }

  display.setTextSize(1);
  display.setCursor(0, 40);
  if (oledMsg.length() && millis() - oledMsgAt < OLED_MSG_MS) {
    display.print(oledMsg);
  } else if (motion && isLocked) {
    display.print("Moi nhap ma PIN...");
  } else {
    display.print("WiFi: ");
    display.print(AP_SSID);
  }
  display.setCursor(0, 54);
  display.print("http://");
  display.print(WiFi.softAPIP());
  display.display();
}

// ================= HTTP HANDLERS =================
void sendJson(bool ok, const String& msg) {
  server.send(200, "application/json", "{\"ok\":" + String(ok ? "true" : "false") + ",\"msg\":\"" + msg + "\"}");
}

String jsonBool(bool v) {
  return v ? "true" : "false";
}

void handleRoot() {
  server.send_P(200, "text/html", PAGE_HTML);
}

void handleStatus() {
  String json = "{\"locked\":" + jsonBool(isLocked) +
                ",\"lockout\":" + String(lockoutRemainingSec()) +
                ",\"door\":" + jsonBool(USE_DOOR_SENSOR && doorOpen) +
                ",\"motion\":" + jsonBool(motion) +
                ",\"alarm\":" + jsonBool(alarmOn) +
                ",\"log\":[";
  for (int i = 0; i < logCount; i++) {
    if (i) json += ",";
    json += "\"" + logs[i] + "\"";
  }
  json += "]}";
  server.send(200, "application/json", json);
}

void handleUnlock() {
  touch();
  unsigned long remain = lockoutRemainingSec();
  if (remain > 0) {
    sendJson(false, "Sai quá nhiều lần! Thử lại sau " + String(remain) + "s");
    return;
  }

  String pin = server.arg("pin");
  pin.trim();
  if (!isValidPin(pin)) {
    sendJson(false, "PIN không hợp lệ (chỉ 4-8 chữ số)");
    return;
  }

  if (safeEquals(pin, currentPin)) {
    unlockDoor("PIN trên web");
    sendJson(true, "Mở khóa thành công!");
    playSuccess();
    return;
  }

  failCount++;
  addLog("Sai PIN lần " + String(failCount));
  if (failCount >= MAX_FAILS) {
    failCount = 0;
    lockedOut = true;
    lockoutStart = millis();
    showMsg("Sai PIN qua 3 lan!");
    startAlarm("sai PIN " + String(MAX_FAILS) + " lần");
    sendJson(false, "Sai " + String(MAX_FAILS) + " lần! Tạm khóa " + String(LOCKOUT_MS / 1000) + "s");
  } else {
    showMsg("Sai PIN! " + String(failCount) + "/" + String(MAX_FAILS));
    sendJson(false, "Sai PIN! Còn " + String(MAX_FAILS - failCount) + " lần thử");
  }
  playFail();
}

// Khóa từ web KHÔNG tắt được báo động: chỉ PIN đúng hoặc nút trong nhà mới tắt được
void handleLock() {
  touch();
  lockDoor("web");
  sendJson(true, "Đã khóa cửa");
}

void handleChangePin() {
  touch();
  String oldPin = server.arg("old");
  String newPin = server.arg("new");
  oldPin.trim();
  newPin.trim();

  if (lockoutRemainingSec() > 0) {
    sendJson(false, "Đang bị tạm khóa");
    return;
  }
  if (!safeEquals(oldPin, currentPin)) {
    addLog("Đổi PIN thất bại (sai PIN cũ)");
    sendJson(false, "PIN cũ không đúng");
    return;
  }
  if (!isValidPin(newPin)) {
    sendJson(false, "PIN mới phải gồm 4-8 chữ số");
    return;
  }

  currentPin = newPin;
  prefs.putString("pin", currentPin);
  addLog("Đã đổi PIN");
  showMsg("Da doi PIN");
  sendJson(true, "Đổi PIN thành công!");
}

// ================= SETUP / LOOP =================
void setup() {
  Serial.begin(115200);

  pinMode(PIN_RELAY_LOCK, OUTPUT);
  pinMode(PIN_RELAY_ALARM, OUTPUT);
  setRelay(PIN_RELAY_LOCK, false);
  setRelay(PIN_RELAY_ALARM, false);
  pinMode(PIN_LED_GREEN, OUTPUT);
  pinMode(PIN_LED_YELLOW, OUTPUT);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  pinMode(PIN_BTN_EXIT, INPUT_PULLUP);
  pinMode(PIN_BTN_LOCK, INPUT_PULLUP);
  pinMode(PIN_DOOR_IR, INPUT);
  pinMode(PIN_PIR, INPUT);

  Wire.begin(21, 22);
  oledOk = display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR);
  if (!oledOk) Serial.println("[WARN] Khong tim thay OLED (thu doi dia chi 0x3D)");

  prefs.begin("smartlock", false);
  currentPin = prefs.getString("pin", DEFAULT_PIN);

  if (USE_DOOR_SENSOR) doorOpen = readDoorOpen();
  lockDoor("khởi động");

  WiFi.softAP(AP_SSID, AP_PASS);
  Serial.print("WiFi: ");
  Serial.println(AP_SSID);
  Serial.print("Mo trinh duyet: http://");
  Serial.println(WiFi.softAPIP());

  server.on("/", HTTP_GET, handleRoot);
  server.on("/status", HTTP_GET, handleStatus);
  server.on("/unlock", HTTP_POST, handleUnlock);
  server.on("/lock", HTTP_POST, handleLock);
  server.on("/changepin", HTTP_POST, handleChangePin);
  server.begin();

  touch();
}

void loop() {
  server.handleClient();
  handleButtons();
  readSensors();

  // Tự khóa lại khi hết thời gian VÀ cửa đã đóng
  if (!isLocked && millis() - unlockedAt >= AUTO_LOCK_MS && !(USE_DOOR_SENSOR && doorOpen)) {
    lockDoor("tự động");
  }

  if (alarmOn && millis() - alarmStart >= ALARM_MS) stopAlarm();

  updateYellowLed();

  static unsigned long lastDraw = 0;
  if (millis() - lastDraw >= 200) {
    lastDraw = millis();
    drawOled();
  }
}
